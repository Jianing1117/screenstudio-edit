# 指示文字自动缩放

在初剪后运行 `zoom-prepare → zooms → zoom-apply`；也可对现有工程仅添加缩放。与剪切计划分开，不触碰 `plan.json`、切口、速度、音轨或已有缩放。默认另存 `<初剪名>-指示缩放.screenstudio`；路径存在时停止，用 `zoom-apply --output /path/新名字.screenstudio` 选择新位置。

## 脚本做什么

- 读取录制鼠标移动及屏幕坐标；不读取键值。不把一直闲置的鼠标当强调。新移入并停留约 1.5 秒，或约 2 秒内有明显水平往返，才抽帧。
- 仅处理保留片段；原片坐标乘 `timeScale` 换算成片位置，变速后的缩放至少约 1.8 秒。默认约 3.75 秒，限制在当前片段内。同一片段同一文字可合并至 10 秒；相邻不同目标留出复核，减少反复推拉。
- 抽起点、中间、终点，检查画面稳定；中间帧用 Apple Vision 本地 OCR。只处理指针附近的较小文字，结合附近口播做保守的文字重合检查。它是候选证据，不代替 AI 的语义判断。
- 2 倍视野要容纳完整 OCR 行及边距。过长句子、疑似翻页标为 blocked，直接保留原画面；口播不匹配或目标间隔太近标为 review，默认不加。已有缩放及其附近优先，不修改、替换或叠加。
- 固定目标对准整行中部，避免跟随鼠标抖动。生成 Screen Studio 原生 `manual` / `screen` 缩放，可在编辑器调整。基础 MP4 预览不呈现此效果。

## AI 只复核不确定项

`zooms --work-dir /path/work` 默认仅返回 review，每页 10 条；支持 `--status auto|review|blocked|all --offset N --limit N`。条目含原片／成片时间、文字框、附近口播、原因及单帧路径；按需看局部，不把全片图片交给模型。blocked 无需 AI 重复确认保留，只汇报数量。

`zoom-plan.json` 的 `decisions` 可写：

```json
{"id":"Z候选编号", "decision":"keep", "reason":"这里需要看全页"}
```

`keep` 表示不新增缩放；`add` 表示经复核确认指示文字与口播一致。只有整句放得下且画面稳定才接受 add；宽句、翻页请在 Screen Studio 手动定范围，不能为了自动化裁断句子。未复核项自动跳过并在 `zoom-applied.json` 列出，不阻塞其余自动项。重新准备后仅在证据完全一致时沿用决定，否则存档旧计划。

## 缓存、环境与边界

使用当前工作目录的 `media/key.json` 与 `media/transcript.json`；其他同源 prepare 目录用 `--cache-from /path/旧工作目录`。无绑定转录时只出待复核项，绝不自动上传或重转录。缓存按录制内容、鼠标轨迹、转录和检测版本分目录；重复运行复用抽帧及 OCR。工程、鼠标或媒体有变更时执行会拒绝旧证据。

需要 macOS Vision 和 Xcode Command Line Tools（`xcrun clang`）；首次调用把随附的 Objective-C 小工具编译进工作目录，不安装 Python OCR 包、不调用云端 OCR。AI 复核时才按需查看单帧。缺依赖时说明并保留初剪，不能声称已完成缩放。当前支持原始全幅裁剪；工程另有画面裁剪时暂停此阶段，人工处理。

缩放规则保守，可能漏掉没有鼠标指示的重点或 OCR 认错的文字；在 Screen Studio 实际检查新增段，再交付。汇报程序验证、原生画面检查和用户听审的实际范围，不能互相替代。
